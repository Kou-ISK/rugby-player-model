# モデルカード — 暫定的な研究基盤

[English](MODEL_CARD.md) | [日本語](MODEL_CARD.ja.md)

状態：**未較正であり、人間の認知やラグビー能力を再現する妥当性は未確認**です。判断原則から独立した実行可能な選手モデルを扱います。packageは `0.4.0`、新しいtraceは `cognition-0.4.0`・Trace 4に統一し、知覚・運動・比較仮説を設定として扱います。コードは[再現manifest](../../reproducibility.json)を含むcommitとソースhashで識別し、`A0` のようなルール版だけでは特定できません。

## 目的

手書きの決定論的な仮説検証モデルで、知覚、注意、記憶、不確実な信念、行為評価、意図、対応能力を示す出力を分離します。学習済みニューラル重み、適合データ、報酬最適化はなく、特定選手の認知を復元しません。指導は候補を作り、人が採用する変更は実験であって学習成功の証拠ではありません。

合成選手の情報を調べ、反証可能な変更を作り、未採用preview、固定条件・反例の比較、成果物別の採否に使います。選手選考、臨床的能力評価、実際の接触の安全指示、試合判定、合成の行動名変更に基づく競技能力の主張には使いません。

## 入出力

| 境界 | 内容と限界 |
|---|---|
| Bundle | 合成の自己状態、見えた証拠、粗い音、時刻・確信度。隠れた位置・意図・未来の真値を含めない |
| Memory | 注意を向けた過去の観測。元の時刻・確信度を保持し、容量・減衰は仮定 |
| Profile | 合成の能力・自己推定・選好・戦術遵守。個人の測定値ではない |
| Rules | 版付き数値・条件規則。コード版・文書版とは別 |
| Trace・身体要求 | 証拠、不確実性、得点、意図、対応／非対応の出力。意図と実行は別 |

世界を含むsnapshotは評価者用の包絡です。認知へ渡すのは検証済みbundle/memory/profile/rulesだけで、snapshot出力は隠れた世界を選手の知識にする許可ではありません。

## 工学的仮定

基準となる知覚・認知の既定値は水平90°、視距離35m、円形遮蔽、粗い音方向、4知覚の符号化、4信念の表示抜粋（判断容量の制約ではない）、128エピソード、寿命30秒です。減衰、不確実性の拡大、重みは未較正です。可変画角、[方向・局面](spec/ORIENTATION_PHASE.ja.md)、[H-WM-1](spec/H-WM-1.ja.md)、[閉ループ](spec/CLOSED_LOOP.ja.md)の仮定は現行形式内の設定として明示します。得点・確信度は成功確率ではありません。

記憶の不確実性は接近の評価や再観測に作用し、音の意味・方向は首振りを導けます。しかし隠れた選手の存在を証明せず、古い受け手情報を新鮮にせず、移動後の音源位置も正確には復元しません。再検出しなかっただけで記憶の選手を消す処理はありません。

## 能力と失敗要因

合成知覚、有界記憶、追跡可能な判断、観測再生、profileを保持した回帰、事前凍結条件、実験記録、候補修正、独立採否・undo・保存に対応します。運動学的設定では意味的callとパスの意図を扱い、他選手は指定経路です。motor設定は加減速・旋回、抽象的パス・捕球・接触、独自観測を持つ選手を追加しますが、完全な物理・規則ではありません。

生物学的妥当性、学習した戦術、関節・筋肉・姿勢、現実的な接触・飛行・キック、音声、独立眼球、全局面・規則、集団協調の実証、試合結果は未達です。P2P形状は描画専用で技能の証拠ではありません。限定MIT許諾は [LICENSE-SCOPE](../../LICENSE-SCOPE.ja.md)、過去のUNLICENSED表示は来歴です。

見えない＝空、確信度の過信、得点最大＝最適、意図＝成功、既知のパラメータ差＝未見検証、コード変更＝ルールだけの変更、という混同に注意します。UIと試験は区別を示すもので、人間の妥当性を証明しません。

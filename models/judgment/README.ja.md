# 判断原則

[English](README.md) | [日本語](README.ja.md)

許可された場面説明とともに[判断原則](RUGBY_JUDGMENT.ja.md)を使います。選手モデルのrunner、ビューア、特定のAI製品、APIは不要です。[選手役のガイド](PLAYER_GUIDE.ja.md)は、一人の選手の情報境界、毎回の判断過程、簡潔な出力記録を定めます。

現行の閲覧版は未採用の草案です。実行可能な選手モデルとも、各私的sessionで採用した文書とも独立しています。翻訳やrepository編集だけで原則を採用しません。評価に使う文書は、言語・全文・hashを固定してください。

**原則なし／旧版／新版**の独立比較は[判断原則の評価手順](../../tools/workbench/docs/JUDGMENT_EVALUATION.ja.md)に従います。同じ観測だけの入力を新しい会話に渡し、原則への適合と競技的妥当性を別々に採点します。取り込んだ提案や外部回答は、明示的レビューまで未承認・未検証です。

[レビュー基準](docs/REVIEW.ja.md)と[合成評価場面](docs/EVALUATION_SCENES.ja.md)は、runner不要の手動評価を支えます。公開例は一度触れた後は回帰用であり、永久に未見の証拠ではありません。[原資料](archive/README.ja.md)は元の草案・初期基準文書・レビュー手順・場面集のバイト列を保存します。sessionのexportは保存された正確な基準文書と順序付き承認済み修正から構成し、全文置換には別の本人判断が必要です。

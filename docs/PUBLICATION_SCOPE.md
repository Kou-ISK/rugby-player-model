The scope above describes this draft's contents, not an automatic future release policy. Future inclusion of real observations, imported assets or a full private session requires a separate review of rights, purpose and public scope. For now the concrete outstanding items are P2P acquisition/reuse/hash verification, owner Mac demonstration, empirical calibration and independently recorded B evaluation. They remain visible in the PR and [verification record](VERIFICATION.md).

The reproduction manifest is an integrity and configuration aid, not a signature, rights certificate or scientific validation. Its file list is explicitly limited to public source/specification/test material; it does not collect local session contents or runtime environment variables. A new Git commit identifies new code; a successful hash check alone does not approve changes to A/B or resolve the license decision.

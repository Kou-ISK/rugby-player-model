# 許諾された公開範囲

[English](PUBLICATION_SCOPE.md) | [日本語](PUBLICATION_SCOPE.ja.md)

本人は2026-10-12に公開を許諾し、その後 [LICENSE-SCOPE](../../LICENSE-SCOPE.ja.md) に記した限定MIT許諾を適用しました。本書は収録範囲を説明し、法的原文は [LICENSE](../../LICENSE) です。誤ったnpm公開を防ぐためpackageはprivateのままです。公開は科学的妥当性、画面受入、研究上の採用と別です。

| 素材 | 公開範囲 |
|---|---|
| 自作の選手モデル、bridge、simulation、experiments、UI | 記載したMIT範囲に含む。研究候補を自動採用しない |
| 設計、カード、判断原則、合成評価場面 | 含む。凍結した評価原本のbytesと歴史的参照を維持 |
| 自作fixture、候補例、再現manifest | 合成素材を含む。実選手データや私的sessionは含まない |
| P2P手続きgeometry | 固定した `tools/workbench/src/rendering/vendor/phrase2play/models.ts` だけ。原本bytesと帰属を保持 |
| 最小姿勢型と来歴 | kit自作の `contact-pose.ts` と来歴記録だけ。P2P core契約や素材全体の許諾ではない |
| 依存物 | lockfileから導入。プロジェクト自作物として再許諾せず各条件・通知を保持 |
| 論文・ラグビー規則 | リンクと短い要約だけ。文書集の転載や推奨の表明ではない |
| 私的計画・ZIP原本、転送情報、識別子、認証情報、私的ログ | 対象外 |
| 私的session、指導・会話、実sessionの画像、個人情報、実試合・選手データ | 対象外 |
| その他P2P基盤・素材、GLB、未確認の将来のimport | 対象外 |

[来歴](PROVENANCE.ja.md)に確認済みの原本識別を記録しています。過去のUNLICENSED通知とkitの旧公開状態は来歴として維持します。現在の許諾は日付付きの限定範囲であり、すべてのimport素材へ及ぶ変更ではありません。

将来のデータ・素材には権利、目的、公開範囲の個別確認が必要です。公開合成提案は許諾済みの収録物と来歴を列挙します。session出力は自動で公開・許諾済みになりません。manifestは明示した公開コード・仕様・試験だけを列挙し、session内容や環境変数を収集しません。hash確認は署名、権利証明、研究採用、実証的妥当性ではありません。

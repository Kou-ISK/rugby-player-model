# Private research checkpoint template

[English](RESEARCH_CHECKPOINT.md) | [日本語](RESEARCH_CHECKPOINT.ja.md)

Copy this template into the private session as `work/research-checkpoint.md`; keep actual entries outside Git. This is a human/assistant note, not a bridge schema or adoption record. Read [RESEARCH_START](RESEARCH_START.md) and [RESEARCH_LOOP](RESEARCH_LOOP.md). Fill only evidence-supported fields; use **unknown**, **not measured** or **not performed** instead of plausible inventions. Link detailed records rather than duplicating full contexts.

## Evidence index

| Local evidence ID / file | Source type | Actual observation / candidate / revision | Exact original text file | New information / interpretation / uncertainty |
|---|---|---|---|---|
| Unfilled | Unclassified | None | None | Not recorded |

Source types: scene-linked coaching, verbal scenario, general principle, human action log, participant report, model experiment, software check, or process direction. Only use matching acquired snapshot/interval/receipt references; for verbal-only evidence use **none** and record the stated premise. A historical conversation anchor, if retained, is not a matching observation. Never label a hypothetical case as viewed or a paused camera trace as gaze. Keep coach recommendations distinct from what a player actually did, and available information distinct from attended/recalled information.

## Gates for a later mechanism proposal

- Scoped attack/defense/role/information coverage, or explicit exclusions:
- Competing explanations and counterexamples examined:
- Inputs, use of history, uncertainty, action continuation/switching and outputs specified:
- Observable predictions, failure criteria, adequate tool capabilities and simpler controls:
- Same motor capabilities across cognitive comparisons:
- Reserved unseen conditions and independent judgment-document evaluation plan:
- For self-organization: independent observations/memory, mutual response, perturbation/repair measures:
- For human-mechanism claims: actual temporally informative human behavior, intervention, alternative-model comparison and transfer; distinguish from instruction agreement:
- Missing evidence and next collection action:

A filled note or a scene count does not pass a gate by itself. No automatic implementation/adoption. Record evidence for each criterion; if insufficient, remain in discovery or narrow the claim.

# 合成シミュレーション

[English](README.md) | [日本語](README.ja.md)

世界生成、知覚、身体実行、読取専用の再生は研究道具です。選手モデルが使える観測を構築するのはsensorだけです。旧場面の他選手は静止または指定経路で動き、パス・接触は実行非対応の意図です。任意選択のscene v3は制約付き運動、球・接触の抽象化、独立した選手を追加します。工学的仮説であり、妥当性を確認したラグビー物理ではありません。
